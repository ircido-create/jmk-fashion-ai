# JMK MODAS

Crie um sistema moderno chamado 'JMK ADM' com sistema de login, contas a pagar, contas a receber, controle de estoque, configuração de whatsapp para SRD com inteligencia artificial, banco de dados configurado. Segmentação: Loja de roupas femininas. O objetivo, é que a IA faça o atendimento dos clientes, passando: Valores, datas de vencimento, envio de cobrança para inadimplentes e responda-os dizendo-lhe preço, tamanho e variações da roupa. Com uma abordagem amigável, acolhedora e que sempre que dizerem Paz Deus, A paz de Deus ou derivados, ela diga Amém. Inclua uma assistente virtual para tirar duvidas dos usuarios. Deve conter no sistema também, controle de usuarios com CRUD completo. Design moderno com animações e estilo liquid glass IOS design estilo bling
